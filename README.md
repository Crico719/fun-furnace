# Game Weaver

Quiero una app donde se pueda jugar cualquier juego, con la base preparada para que los videojuegos se incorporen como componentes dentro de la aplicación.
El contenedor del juego activo debe abrirse en pantalla completa / vista dedicada con barra de controles (pausar, reiniciar, pantalla completa y volver al catálogo) y registro modular para añadir nuevos juegos. Incluye un par de juegos de ejemplo montados como componentes para demostrar la integración.
